# Chronos lesson revision

The [lesson revision runbook](../../../docs/content/lesson-voice-revision-runbook.md) owns the whole process, including the audit that decides which parts (the telling, each prompt, the card) need work. It calls the [prompt revision runbook](../../../docs/content/prompt-revision-runbook.md) when a prompt must be replaced. Read the revision runbook and only the parts of the [lesson creation runbook](../../../docs/content/lesson-creation-runbook.md) it names. Do not read the PRD, design system or other product docs. If the revision runbook is missing, say so and stop; do not reconstruct the process from memory.

Carlin does not need to say which parts to change. A request that would change what the lesson teaches is a material revision: stop and use the `chronos-lesson-production` skill.

In a Cowork or cloud session linked to Carlin's computer, also read [Git and file access for Cowork and cloud agent sessions](../../../docs/content/lesson-production/cowork-git.md).
