# Chronos journey production queue

Linear anchor: [ASH-68 — Map and maintain the canonical Chronos journey portfolio](https://linear.app/ashs-workshop/issue/ASH-68/map-and-maintain-the-canonical-chronos-journey-portfolio)

Portfolio source: [Candidate journey roster](journey-candidate-roster.md)

Status: **Proposed reference runway; no row is yet approved for automatic production.**

This file is the proposed operational companion to the candidate roster. It is intentionally small. The roster may preserve many worthwhile possibilities; the queue should contain only reviewed work with enough clarity to select safely.

## Selection rules

1. Continue one active journey before starting another.
2. Do not promote a candidate from `Proposed` to `Ready` without product/curriculum approval.
3. A `Ready` journey begins with a research and blueprint checkpoint, not lesson implementation.
4. Blueprint the complete journey thesis, chapters, reuse, gaps, framing, synthesis, and Investigation needs before adding journey-driven lesson work.
5. Missing journey entries do not silently change the World Spine or lesson production queue.
6. Prefer a short, publishable first edition that preserves the journey thesis over an impressive but permanently unfinished outline.
7. Only one journey blueprint is normally active; an Investigation engine slice may run separately only with explicit ownership and dependency review.
8. A journey is `Complete` only when its required entries, framing, synthesis, validation, publication, progress behavior, responsive review, and learner-facing preview are approved and merged.

## Status vocabulary

| Status | Meaning |
| --- | --- |
| `Proposed` | Retained and ordered for review; not eligible for automatic selection. |
| `Ready` | Portfolio inclusion and blueprint candidacy approved; dependencies still apply. |
| `Blueprinting` | Journey research, thesis, chapters, entry/reuse audit, and gaps are being designed. |
| `Awaiting approval` | Blueprint decision packet is ready for product/curriculum review. |
| `Staged` | Blueprint approved; missing lesson/media/platform dependencies are being produced. |
| `Implementing` | Approved journey records, framing, synthesis, and learner experience are being implemented. |
| `Review` | Journey PR is awaiting or addressing final review. |
| `Blocked` | A named curriculum, evidence, rights, lesson, or platform dependency prevents progress. |
| `Complete` | Approved, merged, published, verified, and documented. |

## Approval checkpoint

Before any row becomes `Ready`, approve:

- canonical ID and learner-facing title;
- opening question and journey thesis;
- intended first-edition depth;
- main shared lessons and known gaps;
- required versus optional scope;
- platform dependencies;
- accountable historical/editorial reviewers;
- whether production order remains justified by current published content.

Once the first row is approved, the journey-creation runbook should make this prompt sufficient:

> Let’s create the next Chronos journey.
